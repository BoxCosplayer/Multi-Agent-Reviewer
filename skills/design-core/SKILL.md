# Design Core

Create a coherent artifact that can be understood and reviewed without hidden
context.

## Workflow

1. Extract the source's goals, audience, requirements, constraints, and success
   criteria.
2. Record missing information as explicit assumptions rather than silently
   inventing requirements.
3. Produce a complete Markdown body with the structure appropriate to the
   requested artifact.
4. Keep the summary, body, assumptions, decisions, and change log consistent.
5. During revision, resolve or rebut every blocking finding with concrete
   evidence while preserving unaffected sound work.

The final output is text. Do not return images or binary artifacts.
