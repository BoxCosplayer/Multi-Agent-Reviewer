# Review Performance

Apply performance review where the source or artifact has measurable
performance-sensitive outcomes.

- Trace latency, throughput, concurrency, capacity, and resource requirements.
- Identify bottlenecks, serialization points, unbounded work, and degraded-load
  behaviour.
- Check measurement, representative workloads, and performance budgets.
- Do not invent performance requirements for unrelated artifacts.
- Keep speculative tuning and optional optimizations advisory.
