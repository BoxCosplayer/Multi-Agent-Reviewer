# Review Security

Apply security and privacy review in proportion to the artifact and source.

- Identify sensitive assets, actors, entry points, privileges, and boundaries.
- Check identity, authorization, data protection, secrets, auditability, and
  abuse resistance where applicable.
- Check third-party and supply-chain dependencies where applicable.
- Do not force software-specific controls onto an unrelated artifact.
- Block only credible material risks or explicit security/privacy violations.
